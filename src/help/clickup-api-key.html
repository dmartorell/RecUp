Cómo generar tu API Key de ClickUp

La API Key permite a RecUp crear tickets en tu cuenta de ClickUp en tu nombre. La generas una sola vez y la pegas en el modal de ajustes.

1. Abre tus ajustes personales en ClickUp

Inicia sesión en app.clickup.com y haz clic en tu avatar (esquina superior derecha) → Ajustes.

Menú del avatar en ClickUp.

2. Ve a la sección "API de ClickUp"

En el menú lateral izquierdo de la pantalla de ajustes, busca el apartado API de ClickUp.

Sección Apps dentro de Settings.

3. Genera el token en "API Token"

Dentro de esta sección verás la opción Generar Token. Pulsa Generate para crear tu token personal. Cópialo — empieza por pk_.

Generación del token en ClickUp.

Importante: trata el token como una contraseña. No lo compartas ni lo subas a repositorios. Si se filtra, vuelve a esta misma pantalla y pulsa Volver a generar para invalidarlo.

4. Pégalo en RecUp

Vuelve a RecUp, abre Configuración desde el avatar y pega el token en el campo API Key de ClickUp. Guarda.
